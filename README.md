# CPE 010 – CPE21S1 – Data Structures and Algorithms

Laboratory activities, exam, and projects for **CPE 010: Data Structures and Algorithms** at the Technological Institute of the Philippines (1st Semester, S.Y. 2026–2027).

## Course Information

| | |
|---|---|
| **Course Code** | CPE 010 |
| **Section** | CPE21S1 |
| **Credits** | 2 units (laboratory) |
| **Language** | C++ |

## Topics Covered

**Prelim**
- Algorithm analysis, abstract data types, space and time complexity
- Arrays and linked lists (singly, doubly, circular)
- Stacks (array and linked list)

**Midterm**
- Queues (array and linked list)
- Searching: linear search, binary search, hashing
- Basic sorting algorithms

**Final**
- Trees: binary search trees, AVL trees, traversals
- Graphs: adjacency matrix/list, BFS, DFS
- Algorithm analysis and time complexity classes
